# Roadmap 2.004: string support and string library

**Objective:** Add user-facing **string** support and an Augusta **string library** (construction, length, concatenation, slicing, comparison — exact API TBC).

Prerequisite: [2.001](2.001-roadmap-arrays-structures.md) and typically [2.002](2.002-roadmap-allocation-pointers.md); UTF-8 write primitive from [1.002](1.002-roadmap-replace-synthesized-print.md).

## In scope

- String type in the language (representation TBC: bytes + length, etc.)
- Literals and basic operations
- Augusta string module(s)
- Integration with `print` / I/O where appropriate
- Samples + tests

## Out of scope

- Full Unicode algorithms beyond what the first library needs
- Locale-specific formatting

## Status

Not started.
