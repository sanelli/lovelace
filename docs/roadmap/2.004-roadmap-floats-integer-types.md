# Roadmap 2.004: floating point and remaining integer types

**Objective:** Add **floating-point** types and complete **remaining integer type** support beyond the initial signed `integer` / `byte` slice from series 1.

Prerequisite: [1.002](1.002-roadmap-replace-synthesized-print.md) for expressions and operators; extend the type system consistently with [2.002](2.002-roadmap-arrays-type-records.md) where layouts matter.

## In scope

- Floating-point type(s) and literals (IEEE widths TBC)
- Remaining integer widths / signedness the language intends to support
- Conversions / casts between numeric types
- Operator overloading policy (or fixed per-type operators) — lock in implementation issue
- Lowering to Wasm `f32`/`f64` / wider integer ops as applicable
- Samples + tests

## Out of scope

- Soft-float for exotic hosts unless required by a flavor
- Decimal / arbitrary-precision numerics

## Status

Not started.
