# Roadmap 2.004: residual numeric productization

**Objective:** Hold any **leftover** numeric product work that is not covered by [1.002](1.002-roadmap-replace-synthesized-print.md) (literals + minimal `unsigned integer<8>` / `integer<32>` expression slice) or [2.001](2.001-roadmap-more-language-features.md) (remaining `integer<N>` / `float<N>` expression support and the cast matrix).

**Moved out of this roadmap:** floating-point and remaining integer **types**, and **casts** among them, now live in [2.001](2.001-roadmap-more-language-features.md). There is **no** `byte` type — use `unsigned integer<8>`.

Prerequisite: [2.001](2.001-roadmap-more-language-features.md) for the main type/cast work; [1.002](1.002-roadmap-replace-synthesized-print.md) for the initial expression slice.

## In scope (residual / optional)

- Soft-float for exotic hosts if a flavor requires it
- Decimal / arbitrary-precision numerics (if ever productized)
- Other numeric product polish not claimed by 2.001 (lock per issue if anything arises)

## Out of scope

- Core `integer<N>` / `float<N>` expression support and casts → [2.001](2.001-roadmap-more-language-features.md)
- Introducing a `byte` keyword or alias (do not; use `unsigned integer<8>`)

## Status

Not started (empty residual until something is claimed).
