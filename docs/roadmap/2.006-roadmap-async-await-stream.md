# Roadmap 2.006: async, await, future, stream (WASI-aligned)

**Objective:** Add language support for **async**, **await**, **future**, **stream**, and related concepts (exact set **TBC**), aligned with **WASI 0.3** / component-model async so Augusta can call real WASI APIs without narrow synthesized helpers.

Prerequisite: solid sequential language from series 1–2; motivates retiring synthesized I/O primitives such as `PrintUTF8Character` / `PrintUTF8String(unsigned integer<8>[])` (see [1.002](1.002-roadmap-replace-synthesized-print.md), [2.002](2.002-roadmap-arrays-type-records.md)).

## In scope

- Syntax and typing for async procedures / futures / streams (names and grammar TBC)
- Lowering to component-model async, canon builtins, and WASI 0.3 stream/future patterns already used under the hood for stdout
- Error / cancellation policy for v1 (TBC)
- Samples that perform real async WASI I/O from Lovelace source
- Plan to **remove** internal synthesized `PrintUTF8Character` / `PrintUTF8String` (and any remaining print shims) once expressible in-language

## Out of scope

- Full WASI library surface → [3.002](3.002-roadmap-wasi-libraries.md)
- Browser-specific async beyond what web flavor needs for later [3.003](3.003-roadmap-web-libraries.md)

## Status

Not started.
