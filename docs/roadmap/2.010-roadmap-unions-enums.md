# Roadmap 2.010: unions and enums

**Objective:** Add **union** and **enum** types, covering the useful range from **C-style unions** and **Rust / C# / Ada-style discriminated (tagged) unions**, through **C-style enums** and **Java-style enums** (enums as types with richer behavior — exact feature set TBC).

Prerequisite: [2.002](2.002-roadmap-arrays-type-records.md); pattern-matching / functional destructuring may coordinate with [2.011](2.011-roadmap-functional-features.md).

## In scope

- Undiscriminated / C-like unions (safety rules TBC)
- Discriminated / tagged unions (Ada-like variants, Rust-like enums-as-sums, C# union-like patterns — pick and document v1)
- C-like numeric enums
- Java-like enums-as-types (methods / fields on enum values — breadth TBC)
- Lowering, exhaustiveness checks where applicable
- Samples + tests

## Out of scope

- Full functional pattern-matching sugar → [2.011](2.011-roadmap-functional-features.md) (may share match syntax)
- Generic specializations of union/enum wrappers → [2.013](2.013-roadmap-generic-specializations.md)
