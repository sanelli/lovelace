# Roadmap 2.005: string support and string library

**Objective:** Add user-facing **string** support and an Augusta **string library** (construction, length, concatenation, slicing, comparison — exact API TBC), including **conversion between numbers and strings** (and the reverse).

Prerequisite: [2.002](2.002-roadmap-arrays-type-records.md) and typically [2.003](2.003-roadmap-allocation-pointers.md); UTF-8 write primitive from [1.002](1.002-roadmap-replace-synthesized-print.md); numeric/boolean expression rules from 1.002; casts among numbers/booleans from [2.001](2.001-roadmap-more-language-features.md) where relevant.

## In scope

- String type in the language (representation TBC: bytes + length, etc.)
- Literals and basic operations
- Augusta string module(s)
- **Number → string** and **string → number** conversion (API and failure mode TBC — e.g. `Option`/`Result` once available, or checked parse)
- Integration with `print` / I/O where appropriate
- Samples + tests

## Out of scope

- Full Unicode algorithms beyond what the first library needs
- Locale-specific formatting
- Number ↔ boolean casts (those are [2.001](2.001-roadmap-more-language-features.md))

## Status

Not started.
