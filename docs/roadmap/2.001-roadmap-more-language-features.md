# Roadmap 2.001: more language features

**Objective:** Grow the sequential language with additional control-flow, import, and casting constructs beyond the minimal set in [1.002](1.002-roadmap-replace-synthesized-print.md) (which lands one initial loop flavor plus `if`/expressions needed to replace synthesized integer print).

Prerequisite: [1.002](1.002-roadmap-replace-synthesized-print.md). Type records / nested imports interact with [2.002](2.002-roadmap-arrays-type-records.md). Builds on unit-level `import` from [1.001](1.001-roadmap-print-integer-wasi.md).

## In scope

- **More loop forms** not covered by the first loop in 1.002 — e.g. `for`, `until`, `forever`, and similar (exact set and syntax TBC)
- **`switch` / `case` expression**
- **`switch` / `case` statement**
- **Blocks as expressions** — a block can yield a value that may be assigned (`:=`) or discarded
- **Other constructs** drawn from familiar languages where they fit Lovelace’s design (lock per implementation issue)
- **Nested `import`** inside subroutines, type records, code blocks, and similar scopes (not only file-leading unit imports)
- **`import X as Y`** — import a module under an alias (reserved in 1.001; implement here)
- **Unqualified use after import** — ability to `import` module `X` and call its exported subroutines **without** prepending `X.` (exact syntax / “use all” form TBC; must stay unambiguous with local names)
- **Casting** — numbers to numbers; numbers to/from `boolean` (syntax TBC)

## Out of scope

- Arrays / type records themselves → [2.002](2.002-roadmap-arrays-type-records.md)
- `const` / immutable modifiers → [2.014](2.014-roadmap-const-immutable.md)
- Comprehensions / attributes → [2.012](2.012-roadmap-advanced-syntax-attributes.md)
- Functional lambdas / pattern match as a dedicated slice → [2.011](2.011-roadmap-functional-features.md) (coordinate if `switch` overlaps)
- Number ↔ string conversion → [2.005](2.005-roadmap-strings.md)
