# Roadmap 1.003: web flavor — print integer (console)

**Objective:** Support `--flavor web` so a program can print a signed integer to the **browser / JS console** (or equivalent host console binding), with the same public Augusta API as WASI:

```love
export procedure print(value : integer);
```

Prerequisite: [1.001](1.001-roadmap-print-integer-wasi.md). Prefer landing after or alongside [1.002](1.002-roadmap-replace-synthesized-print.md) so the web arm can share Lovelace-authored formatting and only differ in the final write primitive — but a temporary web-native formatter is acceptable if 1.002 is not ready.

## Locked decisions

### `@intrinsic` closed table is flavor-keyed

The compiler’s closed `@intrinsic` mapping table keys each entry by:

| Key component | Role |
| --- | --- |
| **Flavor** | Active compile flavor (`wasi` / `web` / `native`, …) |
| **Module name** | Owning module (e.g. `augusta.std.io`) |
| **Procedure name** | Unqualified subroutine name |
| **Parameter types** | Ordered formal types |
| **Return type** | Result type (usually `Unit`) |

Consequently:

- Two `@intrinsic` procedures with the **same** module + name + signature + return type but **different flavors** are **distinct** table entries — **no clash**
- Matching uses the **current** `--flavor` (or project default); an intrinsic registered only for `wasi` is unknown under `web` unless a web row exists (and vice versa)
- Unknown combination → existing unknown-intrinsic diagnostic (`LV00025` or successor), not a silent empty body

This extends the matching rule locked in [1.002](1.002-roadmap-replace-synthesized-print.md) (which already includes flavor in the key) so web (and later native) can ship flavor-specific synthesized bodies without renaming Augusta APIs.

## In scope

- Real `#if flavor = "web"` body in `augusta.std.io` (replace empty stub)
- Backend / host glue to emit or link a web-capable artifact that can call into JS console (or a thin `console.log`-style import)
- CLI `--flavor web` producing a runnable web path (exact artifact layout TBC; may introduce per-flavor output folders here or with [1.004](1.004-roadmap-print-integer-native.md))
- Register web `@intrinsic` row(s) in the flavor-keyed closed table (e.g. web `PrintUTF8Character` or temporary web print intrinsic — TBC in the implementation issue)
- Sample + tests proving integer console output under the web runner policy
- AUnit / integration: same intrinsic name under `wasi` vs `web` resolves to the correct flavor body with no table clash

## Out of scope

- DOM, storage, WebGL/WebGPU, and broad JS API surface → [3.002](3.002-roadmap-web-libraries.md)
- Native OS library / `libaugusta` → [1.004](1.004-roadmap-print-integer-native.md)
- Full string I/O
