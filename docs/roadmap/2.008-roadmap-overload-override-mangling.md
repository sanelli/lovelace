# Roadmap 2.008: overload, override, and name mangling

**Objective:** Define and implement **overloading**, **overriding**, and **name mangling** (ABI / link / LIR symbol rules) so multiple routines can share a source name safely and inheritance/trait overrides resolve correctly.

Prerequisite: callable procedures from series 1; [2.007](2.007-roadmap-inheritance-traits-interfaces.md) if override is tied to that model; [2.006](2.006-roadmap-templates-generics.md) if overloaded/generic instantiations share mangling space.

## In scope

- Overload resolution rules (arity, types, modules — TBC)
- Override rules when inheritance/traits/interfaces exist
- Name-mangling scheme for LIR / Wasm / native exports (stable enough for debugging and FFI)
- Diagnostics for ambiguity and signature mismatch
- Samples + tests

## Out of scope

- Designing the trait/interface system itself → [2.007](2.007-roadmap-inheritance-traits-interfaces.md)
- Package-manager symbol stability guarantees beyond language ABI → [X.001](X.001-roadmap-package-manager.md)
