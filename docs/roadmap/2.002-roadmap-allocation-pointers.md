# Roadmap 2.002: allocation, deallocation, and pointers

**Objective:** Support explicit **allocation** / **deallocation** and **pointers** so dynamic data structures and Augusta APIs can outlive stack frames.

Prerequisite: [2.001](2.001-roadmap-arrays-structures.md) recommended for useful pointees; [1.002](1.002-roadmap-replace-synthesized-print.md) for basic language control flow.

## In scope

- Pointer types and dereference / address-of (syntax TBC)
- Allocate and free (or equivalent) with clear ownership rules for v1
- Diagnostics for obvious misuse where cheap (null, double-free policy TBC)
- Backend / ABI conventions for guest linear memory
- Samples + tests

## Out of scope

- Full GC
- Strings as a polished API → [2.004](2.004-roadmap-strings.md)
- Cross-component resource handles beyond what WASI already requires

## Status

Not started.
