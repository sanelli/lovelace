# Roadmap 2.002: arrays and type records

**Objective:** Add **arrays** and **type records** to the Lovelace language so programs and Augusta can group and index data without strings or full dynamic allocation yet.

Prerequisite: series 1 language basics from [1.002](1.002-roadmap-replace-synthesized-print.md) (locals, expressions, control flow) as needed for usable examples; nested imports / richer blocks from [2.001](2.001-roadmap-more-language-features.md) optional but useful.

## In scope

- Array types (bounds / length policy TBC)
- Type record types and field access
- Literals / construction / assignment rules as required for arrays and type records
- Lowering to LIR + Wasm (static layout first unless allocation lands earlier)
- Samples + tests

## Out of scope

- Heap allocation / pointers → [2.003](2.003-roadmap-allocation-pointers.md)
- Unions / enums → [2.010](2.010-roadmap-unions-enums.md)
- String as a distinct library type → [2.005](2.005-roadmap-strings.md) (may build on arrays/type records)
- Richer initialization / comprehension syntax → [2.012](2.012-roadmap-advanced-syntax-attributes.md)

## Status

Not started.
