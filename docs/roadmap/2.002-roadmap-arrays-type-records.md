# Roadmap 2.002: arrays and type records

**Objective:** Add **arrays** and **type records** to the Lovelace language so programs and Augusta can group and index data without strings or full dynamic allocation yet. Once `byte[]` exists, widen the synthesized UTF-8 print primitive from per-character bytes to a whole buffer.

Prerequisite: series 1 language basics from [1.002](1.002-roadmap-replace-synthesized-print.md) (locals, expressions, control flow, `byte`, `PrintUTF8Character`) as needed for usable examples; nested imports / richer blocks from [2.001](2.001-roadmap-more-language-features.md) optional but useful.

## In scope

- Array types (bounds / length policy TBC)
- Type record types and field access
- Literals / construction / assignment rules as required for arrays and type records
- Lowering to LIR + Wasm (static layout first unless allocation lands earlier)
- Samples + tests

### I/O primitive upgrade: `PrintUTF8String(bytes : byte[])`

After arrays (at least `byte[]`) land, **replace** the [1.002](1.002-roadmap-replace-synthesized-print.md) synthesized

```text
PrintUTF8Character(byte, byte, byte, byte)
```

with a buffer-oriented primitive (name TBC), e.g.:

```text
PrintUTF8String(bytes : byte[])
```

- Lovelace / Augusta call the array form; **no** language exposure of `async` / `future` / `stream`
- Backend / `native(…)` wrapper **synthesizes** converting the guest `byte[]` (ptr + length) into a WASI 0.3 stdout **stream** write (same class of glue as today’s integer print)
- Rewrite `augusta.std.io` (and any callers) to build a `byte[]` and call `PrintUTF8String`; remove `PrintUTF8Character`
- This shim remains temporary until real stream APIs exist in-language ([2.006](2.006-roadmap-async-await-stream.md) / [3.001](3.001-roadmap-wasi-libraries.md))
