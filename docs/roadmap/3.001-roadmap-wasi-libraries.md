# Roadmap 3.001: basic WASI libraries integration

**Objective:** Integrate basic **WASI** capabilities into Augusta (and language bindings as needed): **clock**, **filesystem**, **CLI**, **socket**, **random**, and related WASI interfaces required for real programs.

Prerequisite: [1.001](1.001-roadmap-print-integer-wasi.md) I/O spine; preferably [2.005](2.005-roadmap-async-await-stream.md) for honest async WASI bindings.

## In scope

- Augusta modules wrapping WASI clock, filesystem, CLI (argv/env/exit beyond `run`), sockets, random
- Backend imports / WIT wiring per capability
- Samples + tests per area (capability flags / wasmtime config as required)

## Out of scope

- Web-only APIs → [3.002](3.002-roadmap-web-libraries.md)
- Native-only extras (e.g. threads) → [3.003](3.003-roadmap-native-libraries.md)
- Crypto and other higher-level Augusta libs → [3.004](3.004-roadmap-augusta-libraries.md)

## Status

Not started.
