# Roadmap 1.004: native flavor — wasmtime embed + libaugusta

**Objective:** Support `--flavor native` for printing a signed integer, by integrating the **wasmtime** library and shipping a freestanding native Augusta library:

```text
libaugusta.so / libaugusta.dylib / libaugusta.dll
```

that wasmtime (or the Lovelace native host) can call. The library is **freestanding Ada** invoking system calls, supporting **Linux, Windows, and macOS**.

Prerequisite: [1.001](1.001-roadmap-print-integer-wasi.md). Share formatting strategy with [1.002](1.002-roadmap-replace-synthesized-print.md) where practical.

## In scope

- Real `#if flavor = "native"` body for `augusta.std.io.print(integer)`
- Embed / drive wasmtime as a library from the Lovelace native host path (details TBC in the implementation issue)
- Build and distribute `libaugusta` for Linux / Windows / macOS (shared library naming as above)
- Freestanding Ada implementation of the native print path via OS write syscalls (no full hosted Ada runtime assumptions beyond what freestanding allows)
- Register native `@intrinsic` / synthesis rows in the **flavor-keyed** closed table locked in [1.002](1.002-roadmap-replace-synthesized-print.md) / [1.003](1.003-roadmap-print-integer-web.md) (flavor + module + name + signature + return — no clash with wasi/web rows of the same name)
- Sample + tests for native flavor integer print
- Per-flavor output folders if not already introduced in [1.003](1.003-roadmap-print-integer-web.md)

## Out of scope

- Broader native stdlib (threads, etc.) → [3.004](3.004-roadmap-native-libraries.md)
- Native UI toolkits → [Z.002](Z.002-roadmap-native-ui.md)
- Arbitrary user FFI to Rust/C/Ada packages → [Z.001](Z.001-roadmap-invoke-native-code.md)
