# Roadmap 3.002: basic web libraries integration

**Objective:** Integrate **web** flavor libraries: WASI-equivalent capabilities where applicable, plus browser APIs — **DOM** manipulation, **sessionStorage** / **localStorage** / **IndexedDB**, and broader JavaScript API support (e.g. **WebGL**, **WebGPU**, and similar).

Prerequisite: [1.003](1.003-roadmap-print-integer-web.md); preferably [3.001](3.001-roadmap-wasi-libraries.md) for shared WASI-shaped APIs.

## In scope

- Augusta web modules for DOM and web storage
- IndexedDB bindings (API breadth TBC for v1)
- Graphics / GPU hooks (WebGL, WebGPU) as staged additions
- Host JS glue / import object conventions
- Samples + tests in a headless or scripted browser runner policy

## Out of scope

- Native UI → [Z.002](Z.002-roadmap-native-ui.md)
- Package manager distribution of web assets → [Y.001](Y.001-roadmap-package-manager.md)

Not started.
