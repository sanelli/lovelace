# Roadmap 3.004: basic native libraries integration

**Objective:** Integrate **native** flavor libraries: WASI-equivalent capabilities where applicable, plus **native-only** Augusta modules for OS services (console, threads, processes, pipes, and related).

Prerequisite: [1.004](1.004-roadmap-print-integer-native.md) (`libaugusta` / wasmtime embed); preferably [3.002](3.002-roadmap-wasi-libraries.md) for shared API shapes. Cross-flavor concurrency helpers (atomics/mutex) may live under [3.005](3.005-roadmap-augusta-libraries.md) if implementable portably; OS thread/process control stays here.

## In scope

- Native Augusta modules mirroring WASI clock/fs/CLI/socket/random where it makes sense on OS APIs
- Platform matrix: Linux, Windows, macOS
- Samples + tests

### Native-only Augusta libraries (planned)

| Area | Notes |
| --- | --- |
| **console** | Terminal I/O, color, cursor/TTY helpers, etc. |
| **threads** | Spawn/join threads and related OS threading |
| **processes** | Create/manage OS processes |
| **pipes** | OS pipes / IPC plumbing |

Exact module names and API breadth are locked in implementation issues.

## Out of scope

- Portable containers/numeric/HTTP/etc. → [3.005](3.005-roadmap-augusta-libraries.md)
- Arbitrary FFI to third-party native packages → [Z.001](Z.001-roadmap-invoke-native-code.md)
- Native UI frameworks → [Z.002](Z.002-roadmap-native-ui.md)
