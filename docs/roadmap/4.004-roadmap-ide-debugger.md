# Roadmap 4.004: debugger support for VS Code and IntelliJ

**Objective:** Add **debugger** support to the **VS Code** and **IntelliJ IDEA** (JetBrains) plugins — preferably by **expanding** the existing plugins from [1.005](1.005-roadmap-ide-plugins-build-run.md) / [4.001](4.001-roadmap-project-solution-ide.md) rather than shipping a separate product.

Prerequisite: debugger-facing export from [4.003](4.003-roadmap-debug-info-for-debugger.md); run hosts from [1.005](1.005-roadmap-ide-plugins-build-run.md) (default `lovelace` run; optional wasmtime for wasi; web via browser + wasm-tools).

## In scope

- Debug adapter / IDE integration for breakpoints, step, stack, locals (exact DAP vs JetBrains API TBC)
- Consume compiler `--debug` / [4.003](4.003-roadmap-debug-info-for-debugger.md) artifacts
- Works for the supported run hosts from [1.005](1.005-roadmap-ide-plugins-build-run.md) (at least default `lovelace` run; optional wasmtime for wasi; web/browser + wasm-tools as feasible)
- Reuse project/solution context when [4.001](4.001-roadmap-project-solution-ide.md) is available

## Out of scope

- Implementing the compiler debug-info format itself → [4.003](4.003-roadmap-debug-info-for-debugger.md)
- Package manager UI → [4.002](4.002-roadmap-pack-and-package-manager.md)

## Status

Not started.
