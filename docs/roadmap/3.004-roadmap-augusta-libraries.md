# Roadmap 3.004: more Augusta libraries (native Lovelace implementations)

**Objective:** Add further **Augusta** libraries implemented primarily in **Lovelace** (not thin OS shims), sharing one `.love` source across flavors where possible (`#if` only where a flavor must differ).

Prerequisite: enough language from series 1–2 — especially [2.006](2.006-roadmap-templates-generics.md) for containers / `Result` / `Option` / `complex<T>`, and preferably [2.007](2.007-roadmap-inheritance-traits-interfaces.md) if numeric types expose shared interfaces. Flavor I/O from [3.001](3.001-roadmap-wasi-libraries.md)–[3.003](3.003-roadmap-native-libraries.md) as needed (entropy, files, network).

## Candidate libraries

Order and packaging (one module vs several) are TBC; this is the backlog to prioritize in implementation issues.

| Area | Notes |
| --- | --- |
| **crypto** | Early candidate (hashing, AEAD, etc. — breadth TBC) |
| **containers** | **Requires generics ([2.006](2.006-roadmap-templates-generics.md)):** lists, maps, hashset, dictionaries, multiset |
| **numeric** | Trig, roots, logs, powers |
| **numeric.complex** | Complex numbers; **requires generics** (e.g. `complex<float>`, `complex<decimal>`) and/or numeric types implementing interfaces ([2.007](2.007-roadmap-inheritance-traits-interfaces.md)) so a subset of operations can be shared |
| **serialization** | JSON, YAML, TOML |
| **Result\<T, E\>**, **Option\<T\>** | Sum-type style APIs; typically need generics |
| **compression** | Tar, Zip |
| **timezone** | Time zone database / conversions |
| **datetime** | `DateTime`, `TimeOnly`, `DateOnly`, calendars, etc. |
| **http client** | HTTP client API (transport may be flavor-specific under the hood) |
| **SIMD** | SIMD-friendly numeric/vector ops (host/Wasm capability TBC) |
| **regex** | Regular expressions |
| **timer** | Timers (**maybe** — may overlap WASI/native clocks) |
| **encodings** | Text/binary encodings (UTF-8/16, base64, …) |
| **concurrent** | **Maybe:** atomic operations, mutex, locks (portable layer; OS threads remain [3.003](3.003-roadmap-native-libraries.md)) |

## In scope (per library slice)

- Prefer pure Lovelace implementations with `#if` only where a flavor must differ
- Docs + samples + tests per library
- Clear dependency callouts on generics / interfaces / async when required

## Out of scope

- Native-only console/threads/processes/pipes → [3.003](3.003-roadmap-native-libraries.md)
- Package manager publishing workflow → [X.001](X.001-roadmap-package-manager.md)
- Native UI → [Z.002](Z.002-roadmap-native-ui.md)
