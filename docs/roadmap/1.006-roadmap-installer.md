# Roadmap 1.006: Lovelace installer

**Objective:** Ship an **installer** that places Lovelace **binaries** (and related host artifacts) into a **versioned** install root under the user home or a shared system path, so **multiple Lovelace versions** can coexist, and that can optionally run **IDE plugin installers** when those plugins exist.

Prerequisite: buildable `lovelace` (and related) binaries from series 1; IDE plugins from [1.005](1.005-roadmap-ide-plugins-build-run.md) when plugin install steps are exercised. Marketplace publication of those plugins → [1.007](1.007-roadmap-marketplace-publish.md).

## In scope

- **Versioned install layout** under a stable root (exact path TBC per OS), for example:
  - user: `~/.lovelace/versions/<version>/…`
  - shared / system: e.g. `/usr/local/lovelace/<version>/…` or OS-appropriate Program Files equivalent
- Install **binaries** into that versioned tree (`lovelace` CLI and any companion host binaries required for the shipped slice — TBC with [1.004](1.004-roadmap-print-integer-native.md) / Augusta layout)
- **Multiple versions** side by side; a clear way to select the **active** version (shim on `PATH`, `lovelace` wrapper, or `LOVELACE_HOME` / similar — TBC in the implementation issue)
- Installer forms appropriate to supported hosts (at least a documented scripted install; native packages / GUI installers TBC)
- **Plugin installers (if needed):** optional steps or companion scripts that install / register the [1.005](1.005-roadmap-ide-plugins-build-run.md) VS Code and JetBrains plugins from a local artifact (VSIX / JetBrains plugin zip) into the user’s IDE — without requiring marketplace publication yet
- Uninstall / list-installed-versions enough to manage the versioned tree safely
- Docs: install paths, version switching, plugin install flags, interaction with plugin settings that point at the `lovelace` executable

## Out of scope

- Publishing plugins to the **VS Code Marketplace** or **JetBrains Marketplace** → [1.007](1.007-roadmap-marketplace-publish.md)
- Hypatia / `.pkglove` package distribution → [4.002](4.002-roadmap-pack-and-package-manager.md)
- Implementing the IDE plugins themselves → [1.005](1.005-roadmap-ide-plugins-build-run.md)
- Language / compiler feature work → series 1–2
