# Roadmap 1.005: IDE plugins — configure, build, and run

**Objective:** Ship **IntelliJ IDEA** (JetBrains family; WebStorm primary) and **VS Code** plugins that can be configured with the **Lovelace executable** and **library / Augusta** locations, then **build** and **run** Lovelace code from the IDE.

Prerequisite: working `lovelace compile` / run path from series 1; TextMate grammars from [1.002](1.002-roadmap-replace-synthesized-print.md) macro step 9 preferred for coloring. Project/solution file awareness → [4.001](4.001-roadmap-project-solution-ide.md). Debugger UI → [4.004](4.004-roadmap-ide-debugger.md).

## In scope

- Plugin settings: path to the `lovelace` executable; path(s) to libraries / `AUGUSTA_HOME` (and any other search roots TBC)
- Build actions that invoke the CLI (or equivalent) and surface diagnostics
- Run (configurable; **default = `lovelace` CLI**):
  - **Default:** run via the **`lovelace`** command (works across flavors the CLI supports; preferred IDE default)
  - **Optional:** run via **wasmtime** — **wasi flavor only** (wasmtime does not cover web / other flavors)
  - **`--flavor web`:** still requires a **browser** host, **and** **`wasm-tools`** (or equivalent) to convert the **component-model** artifact to a **non–component-model** (classical Wasm module) setup the browser path expects
- Reuse shared [`ide/textmate/`](../../ide/textmate/) grammars; do not maintain separate highlighters
- Optional early LSP hooks → [`ide/lsp/`](../../ide/lsp/) when that exists

## Out of scope

- Full `.pjlove` / `.slnlove` project model in the IDE → [4.001](4.001-roadmap-project-solution-ide.md)
- Debugger integration → [4.003](4.003-roadmap-debug-info-for-debugger.md) / [4.004](4.004-roadmap-ide-debugger.md)
- Package manager UI → [4.002](4.002-roadmap-pack-and-package-manager.md)
