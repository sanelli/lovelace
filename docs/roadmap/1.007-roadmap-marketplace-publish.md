# Roadmap 1.007: publish IDE plugins to marketplaces

**Objective:** Publish the Lovelace **VS Code** and **JetBrains** plugins to their **respective marketplaces** so users can install them without a local sideload from the [1.006](1.006-roadmap-installer.md) plugin installer path.

Prerequisite: shippable plugins from [1.005](1.005-roadmap-ide-plugins-build-run.md); local install / sideload path from [1.006](1.006-roadmap-installer.md) preferred as a fallback during and after marketplace rollout.

## In scope

- **VS Code Marketplace** (Open VSX as needed): packaging, publisher account / namespace, CI or documented release steps to upload VSIX, listing metadata (README, changelog, icons)
- **JetBrains Marketplace**: plugin XML / signing as required, upload of the JetBrains plugin artifact, listing metadata
- Versioning aligned with Lovelace releases where practical (document the mapping)
- Keep marketplace builds consuming the shared [`ide/textmate/`](../../ide/textmate/) grammars (no forked highlighters)
- Document both marketplace install and the [1.006](1.006-roadmap-installer.md) local/sideload path for air-gapped or pre-release use

## Out of scope

- Building the plugins’ feature set → [1.005](1.005-roadmap-ide-plugins-build-run.md)
- Host binary / versioned CLI installer → [1.006](1.006-roadmap-installer.md)
- Debugger marketplace extras beyond what [4.004](4.004-roadmap-ide-debugger.md) already assumes for those same plugins
- Hypatia package publish → [4.002](4.002-roadmap-pack-and-package-manager.md)

## Status

Not started.
