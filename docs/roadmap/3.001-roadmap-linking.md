# Roadmap 3.001: proper linking system

**Objective:** Replace the v1 “compile everything into **one** component” model with a **proper linking** system (component-to-component / multi-artifact link — exact design TBC).

Prerequisite: multi-unit compile from [1.001](1.001-roadmap-print-integer-wasi.md) (which **defers** true linking here); project/solution builds from [4.001](4.001-roadmap-project-solution-ide.md) may consume the linker.

## In scope

- Link step that can combine separately compiled Lovelace/Wasm component artifacts
- Interaction with LIR `Dependencies`, WIT imports/exports, and flavor-specific hosts
- CLI surface (e.g. link as part of `compile` / project build — TBC)
- Tests for multi-module / multi-package link graphs

## Out of scope

- Package fetch/install → [4.002](4.002-roadmap-pack-and-package-manager.md)
- Native FFI packaging → [Z.001](Z.001-roadmap-invoke-native-code.md)
