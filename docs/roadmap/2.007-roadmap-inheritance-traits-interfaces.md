# Roadmap 2.007: inheritance / traits / interfaces

**Objective:** Add a mechanism for **shared behavior and abstraction** across types — **inheritance**, **traits**, and/or **interfaces** (exact model **TBC**).

Prerequisite: [2.001](2.001-roadmap-arrays-structures.md); preferably [2.006](2.006-roadmap-templates-generics.md) if interfaces constrain generic parameters (e.g. numeric ops for `complex<T>`).

## In scope

- Choose and document the v1 model (classical inheritance vs traits vs interfaces vs a mix)
- Syntax for declaring and implementing the chosen abstraction
- Dispatch rules (static vs dynamic — TBC for v1)
- Interaction with generics where relevant
- Samples + tests

## Out of scope

- Overload / override / name-mangling details as a separate concern → [2.008](2.008-roadmap-overload-override-mangling.md) (coordinate if override is part of this model)
- Full Augusta numeric/complex libraries → [3.004](3.004-roadmap-augusta-libraries.md)
