# Roadmap 2.012: advanced syntax and attributes

**Objective:** Add **advanced language syntax** conveniences and an **attribute** system — for example Python-like **list comprehensions**, richer **array / dictionary initialization** syntax, and declarative **attributes** on declarations (metadata for the compiler, tools, or generators).

Prerequisite: arrays/type records ([2.002](2.002-roadmap-arrays-type-records.md)); dictionaries may need maps from [3.004](3.004-roadmap-augusta-libraries.md) or a language-level map type (TBC). Attributes may feed [X.003](X.003-roadmap-source-generators.md).

## In scope

- Comprehension / generator expression syntax (breadth TBC)
- Array and dictionary (map) initialization literals / sugar
- Attribute syntax on types, subroutines, modules, etc. (grammar and allowed targets TBC)
- Semantics for built-in attributes vs user attributes (TBC)
- Samples + tests

## Out of scope

- Core functional features (lambdas, match) → [2.011](2.011-roadmap-functional-features.md)
- Implementing source generators that *consume* attributes → [X.003](X.003-roadmap-source-generators.md)
