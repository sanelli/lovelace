# Roadmap 4.003: debug info for a debugger

**Objective:** Extend the `--debug` pipeline so the compiler **exports meaningful information for a debugger** (not only LIR/TLIR source spans).

Prerequisite: LIR/TLIR per-instruction source spans from [1.002](1.002-roadmap-replace-synthesized-print.md) macro step 8.

## In scope

- Debugger-oriented debug info derived from (or alongside) `--debug` spans — format TBC (e.g. DWARF, custom Wasm custom sections, source maps, or a Lovelace-specific sidecar)
- Mapping from Wasm / host execution back to Lovelace source locations, locals, and call frames as far as the chosen format allows
- Stability / versioning of the debug export so IDE adapters can rely on it
- Interaction with optimizers → [X.002](X.002-roadmap-optimizers.md) (preserve or correctly update debug info)

## Out of scope

- IDE debugger UI / adapters → [4.004](4.004-roadmap-ide-debugger.md)
- Language feature work → series 1–2

## Status

Not started.
