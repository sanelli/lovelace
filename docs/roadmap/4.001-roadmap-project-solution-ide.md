# Roadmap 4.001: project / solution build and IDE support

**Objective:** Implement **build** for **`.pjlove`** and **`.slnlove`**, and teach the IntelliJ / VS Code plugins to use that project model (open, build, run against a project or solution).

Prerequisite: formats and behaviour owned by [`lovelace/tooling/`](../../README.md) (crate `lovelace_tooling`); configure/build/run spine from [1.005](1.005-roadmap-ide-plugins-build-run.md).

## In scope

- CLI / library support to build a `.pjlove` project and a `.slnlove` solution (source set, exclusions, referenced projects — schemas TBC)
- Implementation in **`lovelace/tooling/`** for parse/validate/write; `lovelace` CLI invokes it
- IDE plugins: open/associate `.pjlove` / `.slnlove`, drive build/run using project settings, respect configured executable and library paths from [1.005](1.005-roadmap-ide-plugins-build-run.md)
- Docs for authors (HOW TO create/build a project and solution)

## Out of scope

- True multi-component linking → [3.001](3.001-roadmap-linking.md)
- `.pkglove` pack / Hypatia → [4.002](4.002-roadmap-pack-and-package-manager.md)
- Debugger → [4.004](4.004-roadmap-ide-debugger.md)
