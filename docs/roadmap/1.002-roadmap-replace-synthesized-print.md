# Roadmap 1.002: replace synthesized integer print with Lovelace

**Objective:** Add the language features needed so `augusta.std.io.print(integer)` can be implemented in Lovelace (as a normal exported interface body), leaving only a smaller synthesized primitive:

```text
PrintUTF8Character(byte, byte, byte, byte)
```

that writes the UTF-8 representation of one character (up to four bytes). The public `print(integer)` stays the stable exported interface; digit formatting and control flow move into Augusta `.love` source.

Prerequisite: [1.001](1.001-roadmap-print-integer-wasi.md) (WASI print spine with temporary `native("wasi", "native-print-integer")`).

**How to execute:** one numbered macro step per implementation issue / PR (or an explicit consecutive range). Do not skip the closing Augusta rewrite and tests. After each Ada edit step, format, build, and run the relevant test crates before moving on.

## Target shape

| Layer | Role |
| --- | --- |
| `export procedure print(value : integer);` | Stable Augusta API (interface stays) |
| Lovelace body of `print` | Format decimal digits / sign using language features below |
| `@intrinsic` synthesized `PrintUTF8Character` | Smallest remaining compiler-generated UTF-8 write (1–4 bytes) |

When this roadmap is done, remove synthesized `native-print-integer`. Prefer calling an `@intrinsic` `PrintUTF8Character` (name TBC) from Augusta rather than a whole-integer formatter in the backend. Distinguish **compiler intrinsics** from **real native FFI** (see locked decisions).

## Locked decisions

### Intrinsics vs native FFI

| Form | Role |
| --- | --- |
| `@intrinsic` | Compiler-synthesized body (no Lovelace instructions). **No parameters.** Matched by the compiler via signature: **module name + procedure name + parameter types + return type**. |
| `@native("shared-library-name", "function-name")` | Real native / shared-library invocation (FFI). Replaces today’s overloaded use of `native("wasi", "…")` for synthesis. |

- Retire procedure-header `native("target", "key")` as the way to request **synthesized** WASI/print bodies.
- Today’s `native("wasi", "native-print-integer")` becomes an **`@intrinsic`** declaration matched by signature (exact intrinsic table locked in the implementation issue).
- **Unknown intrinsic:** if `@intrinsic` is attached to a subroutine whose signature is **not** in the closed intrinsic table, the compiler **must** emit a diagnostic (stable `LV…` code) — do not silently ignore or treat it as an ordinary empty body.
- General attribute syntax beyond these two forms → [2.012](2.012-roadmap-advanced-syntax-attributes.md); this roadmap only lands `@intrinsic` and `@native(…)`.
- Full user FFI packaging / trust → [Z.001](Z.001-roadmap-invoke-native-code.md) / [1.004](1.004-roadmap-print-integer-native.md); 1.002 establishes the **syntax split** and migrates the existing wasi print intrinsic.

Example shape (illustrative):

```love
export @intrinsic procedure PrintUTF8Character(b0, b1, b2, b3 : byte);

{ later / other flavors — real shared-library call }
export @native("libaugusta", "print_utf8_character") procedure PrintUTF8Character(b0, b1, b2, b3 : byte);
```

### Assignment and expressions

| Topic | Decision |
| --- | --- |
| Assignment operator | **`:=` only**; **`=`** is equality comparison |
| RHS of assignment | Any **expression** (type must match the LHS) |
| LHS of assignment | A **left-assignment expression** (lvalue). v1: a single variable. **Reserved for later** (not required in 1.002 bodies): array index (index is an expression), pointer dereference, map/dictionary access, etc. |
| Expressions | May contain **variables**, literals, operators, calls, and parenthesized subexpressions (as each lands) |
| Call actual parameters | Any **expression** whose type matches the formal (replaces integer-literal-only args) |

### Integer literals (replace `#base#`)

Retire Ada-style `#2#` / `#8#` / `#10#` / `#16#`. New prefixes:

| Prefix | Replaces | Notes |
| --- | --- | --- |
| `0b` / `0B` | `#2#` | Binary |
| `0o` / `0O` | `#8#` | Octal |
| `0x` / `0X` | `#16#` | Hexadecimal |
| *(none)* | `#10#` | Decimal only — **no** `#10#` form |

Optional sign and optional `s`/`u` + width suffixes remain as today unless a later step revises them. Update tokenizer, literal interpreter, grammar docs ([`docs/literals.md`](../literals.md), [`docs/token-grammar.md`](../token-grammar.md)), and tests; reject old `#base#` forms.

### Float literals

| Rule | Decision |
| --- | --- |
| Default type | A float literal **without** a trailing `f` is **`float<64>`** |
| `f` / `F` suffix | Trailing **`f`** means **`float<32>`** |
| Forms | Allow `2.3f`, `7f`, `-2.5E3f` (and similar); exact grammar locked in the literal-migration step; document in [`docs/literals.md`](../literals.md) |

### Boolean

| Topic | Decision |
| --- | --- |
| Type | **`boolean`** |
| Literals | **`true`** / **`false`** (keywords) |
| Logical operators | Words only: `and`, `or`, `not`, `and then`, `or else` (no C-style symbols) |

### Numeric and comparison operators

| Class | Operators |
| --- | --- |
| Arithmetic | `+`, `-`, `*`, `/`; integers also **`mod`**, **`rem`** (keywords) |
| Comparison (→ `boolean`) | `>`, `<`, `=`, `<>`, `<=`, `>=` |

Precedence / associativity locked in the first expression-operator implementation issue.

## Note: evolution and eventual removal of `PrintUTF8Character`

**Internal / `@intrinsic` `PrintUTF8Character` is temporary.** Once arrays exist, prefer upgrading to a buffer primitive such as `PrintUTF8String(bytes : byte[])` with a synthesized array→stream wrapper — still without language async/streams (see [2.002](2.002-roadmap-arrays-type-records.md)). That wider shim (and any remaining print intrinsics) must eventually be removed once Lovelace can express the real WASI binding surface — including **async**, **await**, **future**, **stream** ([2.006](2.006-roadmap-async-await-stream.md), [3.001](3.001-roadmap-wasi-libraries.md)).

## Macro steps

### 1. Comments

**Goal:** Allow comments in `.love` so TEMPORARY notes and API docs can live in source.

**Locked:**

- Delimiters **`{` … `}`** (not `(* *)`, not `--`, not `//`)
- **No nesting:** `{` inside an open comment → `Nested_Comment` (`LV00023`); unterminated `{` → `Unterminated_Comment` (`LV00022`); stray `}` → `Stray_Comment_Closer` (`LV00024`)
- Comments are **not tokens** — skipped like whitespace; parser grammar unchanged
- Strings win: `{` / `}` inside `"…"` are not comment delimiters
- `{` / `}` are not punctuation in this slice

Issue: [#35](https://github.com/sanelli/lovelace/issues/35). Docs: [`token-grammar.md`](../token-grammar.md), [`tokenizer.md`](../tokenizer.md). Sample: TEMPORARY note on wasi `print` in [`augusta/augusta.std.io.love`](../../augusta/augusta.std.io.love); [`samples/comments/Comments.love`](../../samples/comments/Comments.love).

**Status:** Done ([#35](https://github.com/sanelli/lovelace/issues/35)).

### 2. `@intrinsic` vs `@native(…)` (replace `native(…)`)

**Goal:** Split compiler-synthesized bodies from real native FFI in the language surface.

**Locked:**

- Forms: `[ export ] @intrinsic procedure …;` and `[ export ] @native("lib", "fn") procedure …;`
- Hard-reject keyword `native(…)` (`Obsolete_Native_Modifier` / `LV00026`) — no compatibility window
- Closed `@intrinsic` table: only `augusta.std.io.print(integer)→Unit` → existing WASI print synthesis (`Print_Integer_Stdout`)
- Unknown `@intrinsic` → `Unknown_Intrinsic` (`LV00025`)
- `@native` = parse + LIR metadata + empty noop body (no shared-library invoke yet)

Issue: [#37](https://github.com/sanelli/lovelace/issues/37). Augusta wasi arm uses `@intrinsic`; HelloPrint is the end-to-end smoke.

**Status:** In progress ([#37](https://github.com/sanelli/lovelace/issues/37)).
