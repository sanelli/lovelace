# Roadmap 1.002: replace synthesized integer print with Lovelace

**Objective:** Add the language features needed so `augusta.std.io.print(integer)` can be implemented in Lovelace (as a normal exported interface body), leaving only a smaller synthesized primitive:

```text
PrintUTF8Character(byte, byte, byte, byte)
```

that writes the UTF-8 representation of one character (up to four bytes). The public `print(integer)` stays the stable exported interface; digit formatting and control flow move into Augusta `.love` source.

Prerequisite: [1.001](1.001-roadmap-print-integer-wasi.md) (WASI print spine with temporary `native-print-integer`).

## Target shape

| Layer | Role |
| --- | --- |
| `export procedure print(value : integer);` | Stable Augusta API (interface stays) |
| Lovelace body of `print` | Format decimal digits / sign using language features below |
| `native(…)` / synthesized `PrintUTF8Character` | Smallest remaining host/WASI write of 1–4 UTF-8 bytes |

When this roadmap is done, remove synthesized `native-print-integer`. Prefer calling `PrintUTF8Character` (name TBC) from Augusta rather than a whole-integer formatter in the backend.

## Language features in scope

Exact syntax is locked in the first implementation issue for this roadmap. Expected surface:

- **Variable declaration** and **assignment**
- **Mathematical expressions and operators** with **precedence**
- **Boolean expressions** and the **`boolean` type**
- **`if` / `then` / `else` expression**
- **`if` / `then` / `else` statement**
- **Some loop form** (flavor TBC — e.g. `while`, `loop`/`exit`, counted `for`; pick one and document)
- **`byte` type** (needed for UTF-8 byte arguments to `PrintUTF8Character`)
- **Comments** in source (so TEMPORARY notes and API docs can live in `.love`)

## Explicitly deferred (later series)

Do **not** pull these into 1.002:

- Arrays, structures → [2.001](2.001-roadmap-arrays-structures.md)
- Allocation / deallocation, pointers → [2.002](2.002-roadmap-allocation-pointers.md)
- Floating point and remaining integer widths → [2.003](2.003-roadmap-floats-integer-types.md)
- Strings / string library → [2.004](2.004-roadmap-strings.md)
- Character types as a first-class user feature beyond byte/UTF-8 emit
- Full language `async` / `await` / `future` / `stream` → [2.005](2.005-roadmap-async-await-stream.md)

## Note: eventual removal of `PrintUTF8Character`

**Internal / synthesized `PrintUTF8Character` must eventually be removed** once Lovelace can express the real WASI binding surface properly — including **async**, **await**, **future**, **stream**, and related WASI 0.3 concepts (see [2.005](2.005-roadmap-async-await-stream.md) and [3.001](3.001-roadmap-wasi-libraries.md)). Until then it is an intentional narrow synthesis so Augusta can print without embedding full component-model async in the language.

## Suggested macro order (TBC in implementation issues)

1. Comments (tokenizer/parser; no semantic effect)
2. `boolean` + relational / logical operators
3. Locals + assignment
4. Integer (and then `byte`) arithmetic with precedence
5. `if`/`then`/`else` statement; then expression form if distinct
6. Loop form (chosen flavor)
7. Synthesize `PrintUTF8Character`; rewrite `augusta.std.io` wasi `print` in Lovelace; delete `native-print-integer`
8. Samples + unit/integration tests (stdout still `42` for HelloPrint; add formatting edge cases)
