# Roadmap 1.002: replace synthesized integer print with Lovelace

**Objective:** Add the language features needed so `augusta.std.io.print(integer)` can be implemented in Lovelace (as a normal exported interface body), leaving only a smaller synthesized primitive:

```text
PrintUTF8Character(byte, byte, byte, byte)
```

that writes the UTF-8 representation of one character (up to four bytes). The public `print(integer)` stays the stable exported interface; digit formatting and control flow move into Augusta `.love` source.

Prerequisite: [1.001](1.001-roadmap-print-integer-wasi.md) (WASI print spine with temporary `native-print-integer`).

## Target shape

| Layer | Role |
| --- | --- |
| `export procedure print(value : integer);` | Stable Augusta API (interface stays) |
| Lovelace body of `print` | Format decimal digits / sign using language features below |
| `native(…)` / synthesized `PrintUTF8Character` | Smallest remaining host/WASI write of 1–4 UTF-8 bytes |

When this roadmap is done, remove synthesized `native-print-integer`. Prefer calling `PrintUTF8Character` (name TBC) from Augusta rather than a whole-integer formatter in the backend.

## Language features in scope

Exact syntax is locked in the first implementation issue for this roadmap. Expected surface:

- **Variable declaration** and **assignment** with operator **`:=`** (not `=`)
- **Numeric expressions and operators** with **precedence**
- **Boolean expressions** and the **`boolean` type**
- **Comparison operators** on numbers (and later other ordered types) producing **`boolean`**
- **`if` / `then` / `else` expression**
- **`if` / `then` / `else` statement**
- **Some loop form** (flavor TBC — e.g. `while`, `loop`/`exit`, counted `for`; pick one and document)
- **`byte` type** (needed for UTF-8 byte arguments to `PrintUTF8Character`)
- **Comments** in source (so TEMPORARY notes and API docs can live in `.love`)

### Assignment

| Operator | Meaning |
| --- | --- |
| `:=` | Assignment (only); **`=`** is equality comparison, not assignment |

### Numeric operators

| Operators | Notes |
| --- | --- |
| `+`, `-`, `*`, `/` | Arithmetic (unary `+`/`-` as needed) |
| `mod`, `rem` | Integer modulus / remainder (**keywords**, for integer types) |

Precedence and associativity are locked in the implementation issue.

### Comparison operators (numeric → `boolean`)

| Operators | Meaning |
| --- | --- |
| `>` | Greater than |
| `<` | Less than |
| `=` | Equal |
| `<>` | Not equal |
| `<=` | Less than or equal |
| `>=` | Greater than or equal |

### Boolean operators (real words only — not C-style symbols)

| Operator | Meaning |
| --- | --- |
| `and` | Conjunction |
| `or` | Disjunction |
| `not` | Negation |
| `and then` | Short-circuit conjunction |
| `or else` | Short-circuit disjunction |

## Note: eventual removal of `PrintUTF8Character`

**Internal / synthesized `PrintUTF8Character` must eventually be removed** once Lovelace can express the real WASI binding surface properly — including **async**, **await**, **future**, **stream**, and related WASI 0.3 concepts (see [2.006](2.006-roadmap-async-await-stream.md) and [3.001](3.001-roadmap-wasi-libraries.md)). Until then it is an intentional narrow synthesis so Augusta can print without embedding full component-model async in the language.

## Suggested macro order (TBC in implementation issues)

1. Comments (tokenizer/parser; no semantic effect)
2. `boolean` + word logical ops (`and` / `or` / `not` / `and then` / `or else`)
3. Locals + assignment (`:=`)
4. Integer (and then `byte`) arithmetic (`+` `-` `*` `/` `mod` `rem`) with precedence
5. Comparison ops (`>` `<` `=` `<>` `<=` `>=`) yielding `boolean`
6. `if`/`then`/`else` statement; then expression form if distinct
7. Loop form (chosen flavor)
8. Synthesize `PrintUTF8Character`; rewrite `augusta.std.io` wasi `print` in Lovelace; delete `native-print-integer`
9. Samples + unit/integration tests (stdout still `42` for HelloPrint; add formatting edge cases)
