# Roadmap 1.002: replace synthesized integer print with Lovelace

**Objective:** Add the language features needed so `augusta.std.io.print(integer)` can be implemented in Lovelace (as a normal exported interface body), leaving only a smaller synthesized primitive:

```text
PrintUTF8Character(byte, byte, byte, byte)
```

that writes the UTF-8 representation of one character (up to four bytes). The public `print(integer)` stays the stable exported interface; digit formatting and control flow move into Augusta `.love` source.

Prerequisite: [1.001](1.001-roadmap-print-integer-wasi.md) (WASI print spine with temporary `native-print-integer`).

**How to execute:** one numbered macro step per implementation issue / PR (or an explicit consecutive range). Do not skip the closing Augusta rewrite and tests. After each Ada edit step, format, build, and run the relevant test crates before moving on.

## Target shape

| Layer | Role |
| --- | --- |
| `export procedure print(value : integer);` | Stable Augusta API (interface stays) |
| Lovelace body of `print` | Format decimal digits / sign using language features below |
| `native(…)` / synthesized `PrintUTF8Character` | Smallest remaining host/WASI write of 1–4 UTF-8 bytes |

When this roadmap is done, remove synthesized `native-print-integer`. Prefer calling `PrintUTF8Character` (name TBC) from Augusta rather than a whole-integer formatter in the backend.

## Locked decisions

### Assignment and expressions

| Topic | Decision |
| --- | --- |
| Assignment operator | **`:=` only**; **`=`** is equality comparison |
| RHS of assignment | Any **expression** (type must match the LHS) |
| LHS of assignment | A **left-assignment expression** (lvalue). v1: a single variable. **Reserved for later** (not required in 1.002 bodies): array index (index is an expression), pointer dereference, map/dictionary access, etc. |
| Expressions | May contain **variables**, literals, operators, calls, and parenthesized subexpressions (as each lands) |
| Call actual parameters | Any **expression** whose type matches the formal (replaces integer-literal-only args) |

### Integer literals (replace `#base#`)

Retire Ada-style `#2#` / `#8#` / `#10#` / `#16#`. New prefixes:

| Prefix | Replaces | Notes |
| --- | --- | --- |
| `0b` / `0B` | `#2#` | Binary |
| `0o` / `0O` | `#8#` | Octal |
| `0x` / `0X` | `#16#` | Hexadecimal |
| *(none)* | `#10#` | Decimal only — **no** `#10#` form |

Optional sign and optional `s`/`u` + width suffixes remain as today unless a later step revises them. Update tokenizer, literal interpreter, grammar docs ([`docs/literals.md`](../literals.md), [`docs/token-grammar.md`](../token-grammar.md)), and tests; reject old `#base#` forms.
### Float literals

| Rule | Decision |
| --- | --- |
| Default type | A float literal **without** a trailing `f` is **`float<64>`** |
| `f` / `F` suffix | Trailing **`f`** means **`float<32>`** |
| Forms | Allow `2.3f`, `7f`, `-2.5E3f` (and similar); exact grammar locked in the literal-migration step; document in [`docs/literals.md`](../literals.md) |

### Boolean

| Topic | Decision |
| --- | --- |
| Type | **`boolean`** |
| Literals | **`true`** / **`false`** (keywords) |
| Logical operators | Words only: `and`, `or`, `not`, `and then`, `or else` (no C-style symbols) |

### Numeric and comparison operators

| Class | Operators |
| --- | --- |
| Arithmetic | `+`, `-`, `*`, `/`; integers also **`mod`**, **`rem`** (keywords) |
| Comparison (→ `boolean`) | `>`, `<`, `=`, `<>`, `<=`, `>=` |

Precedence / associativity locked in the first expression-operator implementation issue.

### Other language pieces in this roadmap

- **`byte` type** (for `PrintUTF8Character` args)
- **Comments** in source
- **`if` / `then` / `else`** statement and expression
- **One loop form** (flavor TBC — e.g. `while`, `loop`/`exit`, counted `for`; pick one and document). More loops → [2.001](2.001-roadmap-more-language-features.md)

## Note: evolution and eventual removal of `PrintUTF8Character`

**Internal / synthesized `PrintUTF8Character` is temporary.** Once arrays exist, prefer upgrading to a buffer primitive such as `PrintUTF8String(bytes : byte[])` with a synthesized array→stream wrapper — still without language async/streams (see [2.002](2.002-roadmap-arrays-type-records.md)). That wider shim (and any remaining print natives) must eventually be removed once Lovelace can express the real WASI binding surface — including **async**, **await**, **future**, **stream** ([2.006](2.006-roadmap-async-await-stream.md), [3.001](3.001-roadmap-wasi-libraries.md)).
