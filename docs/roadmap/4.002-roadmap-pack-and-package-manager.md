# Roadmap 4.002: pack, `.pkglove`, and Hypatia package manager

**Objective:** Implement **`lovelace pack`** for **`.pkglove`**, and ship **Hypatia** — the Lovelace package manager for distributing and consuming Lovelace/Augusta packages, including a protocol to obtain packages **remotely (git)** or **locally**.

Formerly tracked as Series Y item Y.001.

## In scope

- `.pkglove` manifest format and behaviour via [`lovelace/tooling/`](../../README.md)
- `lovelace pack` (and related CLI) to produce a consumable package artifact (layout TBC)
- Package identity, versioning, and dependency resolution
- Install locations and interaction with `AUGUSTA_HOME` / search paths
- Obtain packages from:
  - a **local folder**, or
  - **git** (via libgit2 inside `hypatia/` — see project Hypatia rules)
- CLI commands for add/update/publish (publish may be phased)
- Documentation for authors and consumers

## Out of scope

- Full language reference docs → [4.005](4.005-roadmap-documentation.md)
- Implementing the libraries themselves → series 3
- Compiler analyzers / optimizers / source generators → series [X](README.md)
- Project/solution file formats beyond what pack needs → [4.001](4.001-roadmap-project-solution-ide.md)
