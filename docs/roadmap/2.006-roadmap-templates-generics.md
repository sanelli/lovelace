# Roadmap 2.006: templates / generics

**Objective:** Add **templates / generics** so Augusta and user code can write reusable type-parameterized APIs (e.g. containers, `Result`/`Option`, `complex<T>`).

**Flavor TBC:** generics might attach to **modules**, and/or to **structs / subroutines** (or both). Lock the shape in the first implementation issue.

Prerequisite: [2.001](2.001-roadmap-arrays-structures.md) (and typically [2.002](2.002-roadmap-allocation-pointers.md)) so there are useful types to parameterize; numeric generics interact with [2.003](2.003-roadmap-floats-integer-types.md).

## In scope

- Syntax and name resolution for type parameters (module-level vs type/subroutine-level — TBC)
- Instantiation / monomorphization or equivalent lowering policy (TBC)
- Constraints on type parameters if any for v1 (may wait on [2.007](2.007-roadmap-inheritance-traits-interfaces.md))
- Samples + tests (e.g. a minimal generic container or wrapper type)

## Out of scope

- Full trait/interface system → [2.007](2.007-roadmap-inheritance-traits-interfaces.md)
- Overload / override / mangling rules beyond what instantiation needs → [2.008](2.008-roadmap-overload-override-mangling.md)
- Shipping Augusta containers/crypto/etc. → [3.004](3.004-roadmap-augusta-libraries.md) (depends on this roadmap)
