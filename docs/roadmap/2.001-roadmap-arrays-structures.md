# Roadmap 2.001: arrays and structures

**Objective:** Add **arrays** and **structures** (records) to the Lovelace language so programs and Augusta can group and index data without strings or full dynamic allocation yet.

Prerequisite: series 1 language basics from [1.002](1.002-roadmap-replace-synthesized-print.md) (locals, expressions, control flow) as needed for usable examples.

## In scope

- Array types (bounds / length policy TBC)
- Structure / record types and field access
- Literals / construction / assignment rules as required for arrays and structures
- Lowering to LIR + Wasm (static layout first unless allocation lands earlier)
- Samples + tests

## Out of scope

- Heap allocation / pointers → [2.002](2.002-roadmap-allocation-pointers.md)
- String as a distinct library type → [2.004](2.004-roadmap-strings.md) (may build on arrays/structures)

Not started.
