# Roadmap 2.009: overload, override, name mangling, and variance

**Objective:** Define and implement **overloading**, **overriding**, and **name mangling** (ABI / link / LIR symbol rules) so multiple routines can share a source name safely and inheritance/trait overrides resolve correctly. Include **variance / contravariance** rules for subtyping of parameters and results (and related generic/interface positions where applicable).

Prerequisite: callable procedures from series 1; [2.008](2.008-roadmap-inheritance-traits-interfaces.md) if override is tied to that model; [2.007](2.007-roadmap-templates-generics.md) if overloaded/generic instantiations share mangling space; parameter modes from [2.003](2.003-roadmap-allocation-pointers.md) interact with variance.

## In scope

- Overload resolution rules (arity, types, modules — TBC)
- Override rules when inheritance/traits/interfaces exist
- **Covariance / contravariance / invariance** for parameters, return types, and (if present) generic type-parameter positions — lock positions and defaults in the implementation issue
- Name-mangling scheme for LIR / Wasm / native exports (stable enough for debugging and FFI)
- Diagnostics for ambiguity, signature mismatch, and illegal variance
- Samples + tests

## Out of scope

- Designing the trait/interface system itself → [2.008](2.008-roadmap-inheritance-traits-interfaces.md)
- Generic specializations → [2.013](2.013-roadmap-generic-specializations.md)
- Package-manager symbol stability guarantees beyond language ABI → [4.002](4.002-roadmap-pack-and-package-manager.md)

## Status

**Partial (early ship):** basic **same-module overload by parameter types** is implemented ahead of this roadmap item — parser allows same name with differing param type sequences; semantics resolve by arity + assignability (`Ambiguous_Call` / `LV00033`); IR selects the overload and emits distinct LIR subroutines that **keep the source name** (Call by 1-based index; LIR/TLIR index lists id + signature). Full ABI mangling for link/export, override, and variance remain for this roadmap.
