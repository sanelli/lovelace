# JetBrains IDEs

Future **JetBrains** plugin for Lovelace and LIR.

Same goals as [`../vscode/`](../vscode/): shared [`../lsp/`](../lsp/) and [`../textmate/`](../textmate/) integration, configuration, build/run/debug, and optional WIT/WAT tooling. Aimed to work across JetBrains IDEs in principle; **WebStorm** is the practical primary target.
